# AI x Web3 School Learning Repo

Personal learning journal and proof-of-work for AI x Web3 School.

## Official Links

- Handbook: https://aiweb3.school/zh/handbook/
- Learning Agent prompt: https://aiweb3.school/learning-agent.zh.txt
- WCB course page: https://web3career.build/zh/programs/AI-Web3-School
- WCB Learning page: https://web3career.build/zh/programs/AI-Web3-School#tab=learning
- WCB Agent API docs: https://web3career.build/llms.txt

## Privacy Rule

This repo is designed to be public proof-of-work. Do not commit API keys, wallet private keys, seed phrases, private contact details, unpublished meeting links, internal screenshots, or other people's personal data.

## Structure

- `profile.md`: learner profile, goals, constraints, and output preferences.
- `learning-plan.md`: staged learning plan and weekly cadence.
- `daily/`: daily learning notes and check-in drafts.
- `tasks/`: task notes and submission evidence.
- `experiments/`: small demos, scripts, and prototypes.
- `handbook-feedback/`: feedback items for Handbook pages.
- `hackathon/`: project ideas, design notes, and demo plans.
- `submissions/`: WCB/task submission records.
- `templates/`: reusable daily note and task note templates.
