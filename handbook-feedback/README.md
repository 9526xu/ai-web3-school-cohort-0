# Handbook Feedback

Use this directory to collect feedback that can be indexed, reviewed, and potentially upstreamed to the AI x Web3 School Handbook.

Each item should include:

- Handbook page URL
- Problem description
- Suggested improvement
- Source or learning context
- Severity: typo, unclear concept, outdated material, missing example, broken link, structure suggestion

Recommended filename:

```text
YYYY-MM-DD-short-topic.md
```
