# Hackathon Workspace

Use this directory for project ideas, design notes, demos, and submission planning.

Suggested artifacts:

- `project-brief.md`: problem, user, solution, trust boundary, demo path.
- `design.md`: architecture, workflow, data/tool boundaries, risks.
- `demo-plan.md`: steps to reproduce and present.
- `submission.md`: final links and WCB/showcase notes.
